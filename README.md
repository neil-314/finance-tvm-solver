# Finance TVM Solver

A polished, responsive time-value-of-money calculator that solves for PV, FV, PMT, annual interest rate, or number of periods.

## Features

- Monthly and annual compounding
- Ordinary annuity and annuity-due payment timing
- Mortgage, investment, and retirement presets
- Visible formula, substitution steps, and cash-flow timeline
- Calculation logic separated into `src/finance.ts`

## Run locally

```bash
npm install
npm run dev
```

For educational purposes; not financial advice.
